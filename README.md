# myVisor3D

Visor ligero de modelos 3D para Windows. Abre **FBX**, **OBJ**, **glTF/GLB** y **USD/USDZ** con sus
texturas PBR (incluidos los tiles **UDIM** de Substance Painter), los guarda con las correcciones y
los exporta a **Arnold**. Funciona sin conexión.

## Descargar

**[⬇ Descargar la última versión](https://github.com/pabloY/myVisor3D-descargas/releases/latest)**
y, en el apartado *Assets*, elige:

- **`myVisor3D-Setup-v<versión>.exe`**: instalador (recomendado).
- `myVisor3D-v<versión>-win-x64.zip`: versión portable; descomprímela y ejecuta `myVisor3D.exe`.

**Requisitos:** Windows 10 u 11 de 64 bits y una tarjeta gráfica con WebGL 2. No hace falta ser
administrador ni tener conexión. Usa Microsoft Edge WebView2, que ya viene con Windows; si faltara,
el programa lo avisa. El **RayTracing** necesita además **Blender 4.2 o posterior** (gratuito; no viene
con myVisor3D): renderiza con Cycles, con la tarjeta gráfica si puede. Si no está instalado, el programa
ayuda a indicarlo o a instalarlo.

## Instalar

1. Abre el instalador. Se instala solo para tu usuario y puede añadir **«Abrir con myVisor3D»** al
   menú contextual del Explorador y accesos directos en el menú Inicio y el escritorio.
2. El instalador no tiene firma digital, así que es normal que:
   - el navegador pregunte si quieres conservar el archivo: elige **Conservar**;
   - Windows muestre «Windows protegió su PC»: pulsa **Más información → Ejecutar de todas formas**.

Para desinstalarlo: *Configuración → Aplicaciones → myVisor3D → Desinstalar*.

Cada versión incluye `SHA256SUMS.txt` con la huella de sus archivos, para comprobar la descarga con
`Get-FileHash <archivo> -Algorithm SHA256` en PowerShell.

## Uso rápido

1. Guarda el modelo con sus texturas en una subcarpeta `texturas` (también valen `textures`, `tex`,
   `maps` o `sourceimages`).
2. Pulsa **Abrir**, arrastra el archivo a la ventana o usa *Abrir con myVisor3D* desde el Explorador.

Con el modelo abierto puedes ver el render final, cada mapa por separado o el mapa UV; añadir y
mover focos; ajustar y sustituir texturas por material y tile UDIM; ver el modelo con
**RayTracing** (`T`, con Cycles de Blender) y **guardar** (`Ctrl+S`) en FBX, OBJ, GLB, USD, USDZ, Arnold
(`.ass`) o 3ds Max (`.max`). Los atajos de teclado están al final del panel lateral.
